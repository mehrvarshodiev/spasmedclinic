# SpasMed Clinic

Адаптивный сайт медицинской клиники SpasMed на React, TypeScript и Vite.

## Запуск

```bash
npm install
npm run dev
```

Перед публикацией заполните реальные контакты клиники, сведения о лицензии, цены и данные специалиста. Форма записи использует `/api/appointments`; для реальной отправки заявок необходимо подключить серверный обработчик. Не размещайте секреты Telegram-бота во фронтенде.
